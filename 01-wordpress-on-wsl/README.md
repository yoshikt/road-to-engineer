# 01. WSL で WordPress を手で作る

Windows の中に Linux サーバーを用意し、WordPress を **一つずつ手で** 組み立てます。
そのあと、同じものを Google Cloud に構築して、インターネットに公開します。

## ゴール

| | ゴール |
|---|---|
| 基本編（Day 1〜15） | WSL の Ubuntu に Apache・PHP・MariaDB を入れ、WordPress を動かす。さらに、自分で書いた手順書だけで同じ環境を作り直せる |
| 発展編（Day 16〜24） | Google Cloud の無料枠で VM を作り、無料サブドメインと HTTPS で WordPress を公開する |

## 使う環境

| 項目 | 内容 |
|---|---|
| PC | Windows 11 |
| Linux 環境 | WSL3 + Ubuntu 24.04 LTS |
| エディタ | Visual Studio Code（WSL 拡張機能） |
| Web サーバー | Apache |
| プログラミング言語 | PHP |
| データベース | MariaDB |
| クラウド（発展編） | Google Cloud（Compute Engine の無料枠） |
| ドメイン（発展編） | 無料サブドメイン（DuckDNS） |

> 💡 Docker は使いません。サーバーの仕組みを理解するために、すべて手でインストールし、手で設定します。
