## 1. 今いる場所と、その中身を見る（10分）

ターミナルで Ubuntu のタブを開きます。

### 今いる場所を表示する

⌨️ **Ubuntu で入力**

```bash
pwd
```

> 🔍 **何をしている？**
>
> `pwd` は print working directory（今いるディレクトリを表示する）の略です。

👀 **表示例**（入力しない）

```text
/home/taro
```

`taro` の部分は、あなたのユーザー名になります。

Day 1 で、プロンプトの `~` は「ホームディレクトリ」だと学びました。**ホームディレクトリの本当の場所は `/home/taro`** です。`~` は、それを短く書くための記号です。

### 中身を表示する

⌨️ **Ubuntu で入力**

```bash
ls
```

> 🔍 **何をしている？**
>
> `ls` は list（一覧）の略で、今いるディレクトリの中にあるファイルやディレクトリを表示します。Windows でフォルダを開いて中身を見るのと同じです。

👀 **表示例**（入力しない）

```text
practice
```

Day 1 で作った `practice` が見えれば OK です。

> 💡 Linux では「フォルダ」のことを **ディレクトリ** と呼びます。この教材でも、ここからはディレクトリと呼びます。

## 2. ディレクトリは木の形（10分）

### いちばん上を見る

Linux のファイルやディレクトリは、すべて **`/`（ルート）** というディレクトリから枝分かれしています。

⌨️ **Ubuntu で入力**

```bash
ls /
```

> 🔍 **何をしている？**
>
> `ls` のうしろに場所を書くと、その場所の中身を表示します。`/` はいちばん上のディレクトリ（ルート）です。

👀 **表示例**（入力しない。一部だけ抜き出しています）

```text
bin  boot  dev  etc  home  lib  mnt  opt  proc  root  run  srv  sys  tmp  usr  var
```

木を逆さまにしたような形をしています。

🗺️ **ディレクトリの図**

```text
/
├── etc       … 設定ファイル置き場
├── home
│   └── taro  … あなたのホームディレクトリ（~）
│       └── practice
├── mnt       … Windows のドライブが見える場所（あとで見ます）
└── var
    ├── log   … ログ（記録）置き場
    └── www   … Web サイトのファイル置き場（Day 7 以降で使います）
```

このコースで特によく使うのは、次の3つです。今は「そういう場所があるんだ」くらいで大丈夫です。

| 場所 | 何がある | いつ使う |
|---|---|---|
| `/etc` | 設定ファイル | Apache や PHP の設定を変えるとき |
| `/var/www` | Web サイトのファイル | WordPress を置くとき |
| `/var/log` | ログ（記録） | エラーの原因を調べるとき |

### 住所の書き方：絶対パス

`/home/taro/practice` のように、**`/` から順にたどった場所の書き方** を **絶対パス** と呼びます。住所でいえば「東京都○○区△△ 1-2-3」のように、どこにいても同じ場所を指す書き方です。

設定ファイル置き場に移動してみましょう。

⌨️ **Ubuntu で入力**

```bash
cd /etc
```

👀 **表示例**（入力しない）

```text
taro@PC-NAME:/etc$
```

プロンプトが `/etc` に変わりました。

> ✏️ **自分で打ってみよう**：`/etc` の中身を一覧で表示してください。

<details>
<summary>答え（コマンド）</summary>

⌨️ **Ubuntu で入力**

```bash
ls
```

たくさんのファイルやディレクトリが表示されます。Day 1 で見た `os-release` も、この中にあります。

</details>

## 3. 移動の近道：`~` `.` `..` と相対パス（15分）

毎回 `/` から書くのは大変です。そこで、近道になる記号があります。

| 記号 | 意味 | 例 |
|---|---|---|
| `~` | 自分のホームディレクトリ（`/home/taro`） | `cd ~` |
| `.` | 今いる場所 | `code .` |
| `..` | ひとつ上のディレクトリ | `cd ..` |

### ホームに戻る

> ✏️ **自分で打ってみよう**：`~` を使って、ホームディレクトリに戻ってください。プロンプトが `~` になれば OK です。

<details>
<summary>答え（コマンド）</summary>

⌨️ **Ubuntu で入力**

```bash
cd ~
```

> 💡 `cd` だけを打っても、ホームディレクトリに戻れます。迷子になったら、まず `cd` でホームに帰りましょう。

</details>

### ひとつ上へ

> 🤔 **予想しよう**：ホームディレクトリ（`/home/taro`）で `cd ..` を実行すると、どこに移動するでしょうか？
>
> ✋ **予想をメモしてから、次のコマンドを実行しましょう。**

⌨️ **Ubuntu で入力**

```bash
cd ..
```

> ✏️ **自分で打ってみよう**：今いる場所を表示するコマンドで、どこに移動したか確かめてください。

<details>
<summary>答え合わせ</summary>

⌨️ **Ubuntu で入力**

```bash
pwd
```

👀 **表示例**（入力しない）

```text
/home
```

`/home/taro` のひとつ上なので、`/home` に移動しました。プロンプトも `taro@PC-NAME:/home$` に変わっています。

</details>

### 今いる場所からの書き方：相対パス

ホームディレクトリに戻ってから、`practice` に移動します。

> ✏️ **自分で打ってみよう**：ホームディレクトリに戻ってください。

<details>
<summary>答え（コマンド）</summary>

⌨️ **Ubuntu で入力**

```bash
cd
```

</details>

ホームディレクトリにいるときは、`practice` とだけ書けば移動できます。

⌨️ **Ubuntu で入力**

```bash
cd practice
```

> 🔍 **何をしている？**
>
> `/` から始まらない場所の書き方は、**今いる場所から見た場所** を意味します。これを **相対パス** と呼びます。住所でいえば「ここから2つ先の角」のような書き方です。
>
> ホームディレクトリ（`/home/taro`）にいるので、`practice` は `/home/taro/practice` を指します。

| 書き方 | 種類 | 指している場所 |
|---|---|---|
| `/home/taro/practice` | 絶対パス | どこにいても `/home/taro/practice` |
| `~/practice` | 絶対パス（`~` を使った短縮形） | どこにいても `/home/taro/practice` |
| `practice` | 相対パス | 今いる場所の中の `practice` |

> 🤔 **予想しよう**：今は `~/practice` にいます。ここでもう一度 `cd practice` を実行すると、どうなるでしょうか？
>
> ✋ **予想をメモしてから、実行してみましょう。**

<details>
<summary>答え合わせ</summary>

👀 **表示例**（入力しない）

```text
-bash: cd: practice: No such file or directory
```

「そんなファイルやディレクトリはない」というエラーです。相対パスは **今いる場所から見た場所** なので、`~/practice` の中に `practice` がなければ移動できません。

エラーが出ても、今いる場所は変わりません。プロンプトを見て確かめましょう。

</details>

### 大文字と小文字は別物

> 🤔 **予想しよう**：ホームディレクトリで `cd Practice`（P が大文字）を実行すると、どうなるでしょうか？
>
> ✋ **予想をメモしてから、ホームディレクトリに戻って実行してみましょう。**

<details>
<summary>答え合わせ</summary>

`No such file or directory` のエラーになります。

Windows では、ファイル名の大文字と小文字を区別しません。**Linux では区別します。** `practice` と `Practice` は別の名前です。

</details>

### Tab キーで楽をする

長い名前を全部打つのは大変です。途中まで打って **Tab キー** を押すと、残りを自動で補ってくれます。

1. ホームディレクトリで、`cd pra` まで打ちます（Enter は押しません）。
2. **Tab キー** を押します。
3. `cd practice/` まで自動で入力されます。Enter を押して移動します。

候補が複数あるときは、Tab キーを **2回** 押すと候補の一覧が表示されます。打ち間違いも減るので、どんどん使いましょう。

## 4. 隠しファイルと詳しい表示（10分）

### 隠しファイルを表示する

> ✏️ **自分で打ってみよう**：ホームディレクトリに戻って、中身を一覧で表示してください。

<details>
<summary>答え（コマンド）</summary>

⌨️ **Ubuntu で入力**

```bash
cd
```

⌨️ **Ubuntu で入力**

```bash
ls
```

`practice` だけが表示されます。

</details>

実は、ホームディレクトリには、ほかにもファイルがあります。

⌨️ **Ubuntu で入力**

```bash
ls -a
```

> 🔍 **何をしている？**
>
> `-a` は all（すべて）の略で、**隠しファイル** も表示するオプションです。Linux では、名前が `.`（ドット）で始まるファイルは隠しファイルになり、普通の `ls` では表示されません。

👀 **表示例**（入力しない。環境によって違います）

```text
.  ..  .bash_history  .bash_logout  .bashrc  .profile  .vscode-server  practice
```

- `.bashrc` などは、bash の設定ファイルです。設定ファイルは、ふだん目に入らないよう隠しファイルにされていることがよくあります。
- `.vscode-server` は、Day 1 で VS Code をつないだときにできたものです。
- `.` と `..` も表示されています。**どのディレクトリにも「自分自身（`.`）」と「ひとつ上（`..`）」が入っている** ので、`cd ..` で上に移動できるのです。

### 詳しく表示する

⌨️ **Ubuntu で入力**

```bash
ls -l
```

> 🔍 **何をしている？**
>
> `-l` は long（長い形式）の略で、ファイルの種類や大きさ、更新日時などを詳しく表示するオプションです。

👀 **表示例**（入力しない。日付の表示は環境によって違います）

```text
total 4
drwxr-xr-x 2 taro taro 4096 Nov 14 10:00 practice
```

今日注目するのは、**いちばん左の1文字** だけです。

| 左端の文字 | 種類 |
|---|---|
| `d` | ディレクトリ（directory） |
| `-` | 普通のファイル |

残りの `rwxr-xr-x` や `taro taro` は、Day 4 で学びます。

> 💡 オプションはまとめて書けます。`ls -la` は `ls -l -a` と同じ意味で、隠しファイルも含めて詳しく表示します。

## 5. Windows とのつながり（5分）

> 🤔 **予想しよう**：Ubuntu から、Windows の C ドライブのファイルは見えるでしょうか？
>
> ✋ **予想をメモしてから、次のコマンドを実行しましょう。**

⌨️ **Ubuntu で入力**

```bash
ls /mnt/c
```

<details>
<summary>答え合わせ</summary>

見えます。`Users` や `Windows` など、見覚えのある名前が並びます。WSL では、Windows の C ドライブが `/mnt/c` に見えるようになっています。

`Permission denied` という行が混ざることがありますが、気にしなくて大丈夫です（Day 4 で学びます）。

</details>

反対に、Windows から Ubuntu のファイルを見ることもできます。

⌨️ **Ubuntu で入力**

```bash
explorer.exe .
```

> 🔍 **何をしている？**
>
> `explorer.exe` は、Windows のエクスプローラーです。`.`（今いる場所）を付けたので、Ubuntu の今いるディレクトリがエクスプローラーで開きます。

エクスプローラーのアドレス欄に `\\wsl.localhost\Ubuntu\home\taro` のように表示されれば OK です。

> ⚠️ WordPress などのサーバーのファイルは、`/mnt/c` ではなく **Ubuntu 側**（`/home` や `/var/www`）に置きます。Windows 側に置くと動作が遅くなり、権限の設定もうまくいきません。

## つまずきやすいポイント

| 症状 | 原因と対処 |
|---|---|
| `No such file or directory` と表示される | 名前の打ち間違い、大文字と小文字の違い、今いる場所の勘違いのどれかです。`pwd` と `ls` で確かめましょう |
| 今どこにいるか分からなくなった | `cd` だけを打ってホームに戻り、やり直しましょう |
| Tab キーを押しても補完されない | その名前で始まるものがないか、候補が複数あります。Tab キーを2回押して候補を確かめましょう |
| `ls` で何も表示されない | そのディレクトリが空です。エラーではありません |
| `explorer.exe .` が動かない | `explorer` だけでなく `.exe` まで付けて打ちましょう |
