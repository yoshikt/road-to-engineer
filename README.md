# Road to Engineer

**未経験からはじめる、エンジニアへの道のり**

名前は大きめですが、中身は「1日1時間、一歩ずつ」です。
黒い画面を触ったことがない人でも、最後には自分の手で Web サイトを動かし、インターネットに公開できるようになることを目指します。

## 対象

- プログラミングやサーバーの経験がほとんどない人
- Linux のコマンドを使ったことがない人
- 「なんとなく動いた」ではなく、「なぜ動くのか」まで分かるようになりたい人

## 教材の読み方

### 1日1ファイル

各コースは `day01.md`、`day02.md`… と1日ごとのファイルに分かれています。1回の目安は約1時間です。

### 🤔 マークは「考えてから開く」

🤔 が付いた問いには、折りたたまれた答えがあります。

<details>
<summary>答え合わせ（ここをクリック）</summary>

このように、クリックすると答えが表示されます。
**開く前に、自分の予想を一言でいいので書き出してください。** 予想が外れても構いません。外れたところが、いちばん記憶に残ります。

</details>

### どこで実行するかは、コードブロックの上を見る

コマンドを実行する場所は、コードブロックの言語名で区別しています。

| 言語名 | 実行する場所 |
|---|---|
| `powershell` | Windows の PowerShell |
| `bash` | Ubuntu（Linux）のターミナル |
| `text` | 実行しない（出力例など） |

### コピペより手打ち

最初のうちは、コマンドを **自分の手で打つ** ことをおすすめします。打ち間違えてエラーを見ることも、立派な練習です。
